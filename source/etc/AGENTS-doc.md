# Documentation Instructions

This document describes the way you should handle documentation when working on this project.

- During implementation, you need to keep the updated documentation inside `docs` directory. 
- `docs/Architecture.md` should reflect current version of application architecture, including the overall component description, all APIs and interfaces. 
- `docs/History.md` should reflect all major architectural changed and decisions done during development, so that we can always see the progress, what we have tried, what worked and what not.

Whenever you do any code changes, you need to review documentation and make sure it is updated and current.
