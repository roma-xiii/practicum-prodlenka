# Аниме в Пушкинском — интерактивный прототип

Статическое приложение без сборки: HTML, CSS, JavaScript, репродукции из открытого каталога музея. Для запуска из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:4173. Основной сценарий: карта → путь → задание → впечатление → следующая остановка → итоги. Все восемь остановок доступны с карты в любом порядке. Прогресс, ответы, впечатления и избранное сохраняются в localStorage. Повторное завершение не увеличивает счётчик. Итоги доступны после восьми остановок. На карте есть сброс прогресса с подтверждением. Итоги можно скачать как TXT.

## Mobile first

Базовые стили рассчитаны на телефон: одна колонка, вертикальная линия остановок, крупные кликабельные карточки, закреплённый прогресс, кнопки от 48 px. Расширение до двух колонок добавляется только при ширине от 760 px. Проверены экраны 320 и 390 px.

## Данные и ограничения

- Из `https://pushkinmuseum.art/json/masterpieces.json` извлечены восемь записей (2026-10-03). В `museum-data.js` сохранены ID, полные названия, авторы, даты, эпохи, ссылки на изображения и карточки музея. Изображения загружаются с сайта музея; требуется интернет.
- Этажи и залы взяты из предоставленной пользователем таблицы; актуальность не проверена.
- Репродукции показываются целиком без обрезки и цветовых фильтров. В карточках — атрибуция и ссылка на музейный каталог.
- Навигация показывает последовательность, не фактический путь. API не подключён; доступность залов, переходов и здания не проверена.
- Задания и пояснения — редакционные примеры, требуют проверки по оригиналам.
- Подарок демонстрационный, условия получения не согласованы.
- Шрифты Prata и Manrope загружаются из Google Fonts; предусмотрены системные запасные шрифты.
- Прогресс сохраняется только в данном браузере, без синхронизации.

## SourceCraft Sites

Конфигурация в `../.sourcecraft/sites.yaml`: `root: site`, `ref: main`. Используются относительные URL ресурсов и hash-навигация, чтобы приложение работало в подкаталоге репозитория. Сервер и сборщик не требуются. Для публикации нужны публичные организация/репозиторий и установленный авторизованный CLI `src`. Следовать `../source/skills/sourcecraft-sites/SKILL.md`; переносить только каталог site и конфигурацию хостинга, не включать .env.

API маршрутов в следующей версии должен быть внешним HTTPS-сервисом с CORS для домена сайта. Секретные ключи нельзя включать в статические файлы.

## Тексты маршрута

В `route-content.json` импортированы все восемь уровней из пользовательского JSON; исправлены отсутствующие открывающие кавычки в вариантах ответа уровня 5. `route-content.js` — тот же контент в виде скрипта для статического подключения (обновлять вместе с JSON). Описания, сравнения с аниме, вопросы, пояснения, размеры, материалы и все поля игровых карточек сохранены. Это пользовательский редакционный материал, не проверенные музейные атрибуции; связи с аниме обозначены как интерпретации авторов маршрута.

После выбора любого из четырёх ответов показываются ответ авторов и объяснение. Продолжение доступно независимо от совпадения. Пройденная остановка открывает карточку с редкостью, стихией, классом, способностью и историей; карточки также доступны в итогах. Старые ответы на предыдущие вопросы не переносятся на новую викторину; прогресс и избранное сохраняются. Формат сохранения ответов — `quizVersion: 2`.
